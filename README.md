# Login App Abrahan

Formulario demostrativo de inicio de sesión desarrollado con HTML, CSS y JavaScript.

## Estrategia de ramificación

Este proyecto utiliza GitHub Flow. La rama `main` conserva la versión estable.
Los cambios se desarrollan en ramas cortas y se integran mediante Pull Requests
revisados antes de su fusión. Se verifica que las comprobaciones automáticas
finalicen correctamente antes de integrar los cambios.

## Funcionalidad

El formulario solicita usuario y contraseña y comprueba que los campos no estén
vacíos. Este proyecto no implementa autenticación real, no usa una base de datos
y no transmite credenciales.
